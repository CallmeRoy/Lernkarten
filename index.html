📖 So verwendest du dieses Dashboard

  1. Speichern: Lade diese Datei als index.html in dein GitHub-Repository hoch (z. B. mein-name.github.io/lernkarten/).
  2. Erste Karte: Speichere die vorherige Lernkarte (modul1-tag4.html) im selben Ordner wie die index.html.
  3. Nächste Karte hinzufügen: Wenn du eine neue Lernreflexion erstellst, speichere sie als modul2-tagX.html im selben Ordner. Kopiere dann eine fertige Kachel (z. B. die von Modul 1), passe Titel, Pfad und Text an, und ersetze eine future-Kachel im Raster.
  4. GitHub Pages aktivieren: Gehe in deinem Repository auf Settings → Pages und wähle als Quelle main (bzw. master) und das Root-Verzeichnis. Schon ist dein Dashboard live unter dein-name.github.io/REPOSITORY-NAME/.
  5. Öffentlich oder privat: Funktioniert mit beiden – du entscheidest.
